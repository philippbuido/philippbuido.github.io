On Security

"Security is a process, not a product."

— Schneier, B. (2000). Secrets and Lies. Wiley.

"Companies spend millions of dollars on firewalls, encryption, and secure access devices, and it's money wasted because none of these measures address the weakest link in the security chain: the people who use, administer, operate, and account for computer systems that contain protected information."

— Mitnick, K. D., & Simon, W. L. (2002). The Art of Deception (p. 3). Wiley.

"If it's smart, it's vulnerable."

— Hyppönen, M. (2016). Hyppönen's Law.

Cybersecurity Roadmap

A structured learning path for aspiring cybersecurity professionals. Source: roadmap.sh

🖥️ Stage 1 — Fundamental IT Skills

Computer Hardware · Networking Basics (WiFi, Bluetooth, NFC) · OS Fundamentals (Windows, Linux, macOS) · Common Suites (MS Office, Google Suite) · CTF Platforms: HackTheBox, TryHackMe, VulnHub

🌐 Stage 2 — Networking Knowledge

OSI Model · TCP/IP · DNS, DHCP, NAT · Subnetting · VLANs · VPN · Protocols: HTTP/S, SSH, FTP, RDP · Troubleshooting: nmap, Wireshark, netstat, tcpdump

🔐 Stage 3 — Security Skills & Knowledge

CIA Triad · Cryptography (Hashing, PKI, TLS) · IDS/IPS · Firewalls · Zero Trust · Cyber Kill Chain · ATT&CK Framework · OWASP Top 10 · Malware Analysis · Penetration Testing · Blue/Red/Purple Teams · SIEM & SOAR

☁️ Stage 4 — Cloud Security

Cloud Models (IaaS, PaaS, SaaS) · AWS, Azure, GCP · Infrastructure as Code · Serverless · Cloud vs On-Premises Security

🏅 Certifications

Beginner: CompTIA A+, Network+, Security+, CCNA
Advanced: CEH, OSCP, CISSP, CISM, CISA, GPEN
